You cannot have multiple files with the exact same name in a single directory. If you have duplicate files, they either live in different subdirectories or have different names (like file(1).txt or file - Copy.txt). [1, 2] 
Here is how to delete those duplicates using PowerShell, depending on your exact situation.
## Scenario 1: Identical names in different subfolders
If you have a main folder with many subfolders, and the same filename appears across them, this script keeps the first one found and deletes the rest.

Get-ChildItem -Path "C:\YourFolder" -Recurse -File | 
    Group-Object Name | 
    ForEach-Object { $_.Group | Select-Object -Skip 1 } | 
    Remove-Item -Force

## Scenario 2: True duplicates with different names (by file content) [3] 
If the files have different names (e.g., photo.jpg and photo(1).jpg) but the exact same content, you can group them by their file hash (digital fingerprint). This keeps the oldest file and deletes the rest. [4, 5, 6] 

Get-ChildItem -Path "C:\YourFolder" -File | 
    Get-FileHash | 
    Group-Object Hash | 
    ForEach-Object { $_.Group | Sort-Object { (Get-Item $_.Path).CreationTime } | Select-Object -Skip 1 } | 
    ForEach-Object { Remove-Item $_.Path -Force }

## Scenario 3: Pattern-based duplicates in the same folder
If Windows generated the duplicates in the same folder by adding "Copy" to the name, you can target that specific pattern directly.

Get-ChildItem -Path "C:\YourFolder" -Filter "* - Copy.*" | Remove-Item -Force

## 💡 Safety Recommendation
Before running any deletion command, append -WhatIf to the end of the Remove-Item command. This will simulate the command and show you exactly what would be deleted without actually removing anything. [7, 8]
